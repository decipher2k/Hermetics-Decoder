     Count distinct symbols, motifs, and named entities per unit of text (paragraph or verse).
     Classification:

       σ_medium (2–5 per unit)                   → e.g., narrative allegory, Rosarium
       σ_low    (< 2 per unit)                   → e.g., discursive treatise, commentary

       λ_small   (500–5000 words)     → single treatise
       λ_medium  (5000–50000 words)   → collection / multi-chapter

  I. MASKING — ENFORCED STRUCTURAL BLINDNESS
═══════════════════════════════════════════════════════════════

This is the mechanism that separates decryption from retrieval.

BEFORE any analysis begins, after the assay and prima materia identification:

  1. IDENTIFY all symbolic terms in the corpus.
     A symbolic term is any word or phrase that functions as a symbol — not literal description
     but carrier of encoded meaning. This includes: named entities (Mercury, Sol, Luna),
     allegorical figures (the King, the Queen, the Dragon), process terms (dissolution,
     coagulation, putrefaction), material terms (sulphur, salt, the Stone itself),
     and any term the assay identified as part of the symbolic register.

  2. REPLACE each symbolic term with a neutral placeholder: SYMBOL_01, SYMBOL_02, ... SYMBOL_nn.
     The replacement must be consistent across the entire corpus (same term → same placeholder).

  3. WRITE the mapping table to masking/symbol_map.json:
     { "SYMBOL_01": "original_term_1", "SYMBOL_02": "original_term_2", ... }

  4. SEAL the mapping table.
     ┌─────────────────────────────────────────────────────────────────┐
     │  THE AGENT MUST NOT READ masking/symbol_map.json               │
     │  UNTIL AFTER INNER-LOOP CONVERGENCE.                           │
     │                                                                 │
     │  This is the central discipline of the entire system.           │
     │  If the agent reads the map during decryption, the process     │
     │  degenerates into retrieval. The mask IS the transmutation.    │
     └─────────────────────────────────────────────────────────────────┘

  5. WRITE the masked corpus to masking/masked_corpus.txt.
     This masked version is the SOLE input for all subsequent phases.
     The original unmasked corpus exists only in prima_materia/original_corpus_snapshot/
     and must not be read again until demasking.

  6. WRITE masking/masking_report.md documenting:
     — Total number of distinct symbols masked
     — Classification of each (entity / figure / process / material / other)
     — Structural connectives left unmasked (and, but, therefore, above, below, etc.)
     — Any ambiguous cases and how they were resolved

WHAT REMAINS UNMASKED:
  — Structural connectives (and, or, but, if, then, therefore, because, above, below)
  — Quantifiers (one, two, three, all, none, many)
  — Temporal markers (first, then, after, before, when)
  — Spatial markers (above, below, inside, outside)
  — Verbs of action and transformation (in their generic form — "transforms" stays,
    but "calcination" is masked because it names a specific symbolic process)

The point: the grammar, the syntax, the relational skeleton of the text stays visible.
The symbolic content is hidden. The agent must reconstruct what each placeholder DOES
before learning what it was CALLED.

═══════════════════════════════════════════════════════════════

The prima materia is the encrypted core substrate of the corpus. Identify it BEFORE masking (it needs the raw terms to apply the indicators), but document it using the masked placeholders as well.

Identify algorithmically by scanning the entire corpus for these convergent indicators:

  • Ubiquity with concealment: recurring base motif serving as implicit origin, overlooked or disguised.
  • Paradoxical naming: one underlying layer described with contradictory or excessive symbolic labels.
  • Formlessness & undifferentiated potential: chaotic/pre-differentiated passages containing latent opposites.
  • Cyclical origin & return: element to which the corpus repeatedly regresses and from which transformations originate.
  • Maximal symbolic density: passages exhibiting informational redundancy or entropy peaks.

Once identified, designate this as the immutable encrypted prima materia. Save:
  — prima_materia/identified_prima_materia.json (with both original terms AND masked placeholders)
  — prima_materia/justification_trace.md
  — prima_materia/original_corpus_snapshot/ (immutable, unmasked, sealed — not read during decryption)

NEVER overwrite or mutate the source material.

The score has three components:

  A) DELTA SCORE (Δ) — Marginal Improvement
     Compare draft_v{n} against draft_v{n-1} (if exists).
     Measure:
       — Number of substantive changes (not cosmetic rewording)
       — Number of contradictions resolved vs. prior iteration
       — Number of UNSTABLE symbols that moved to SETTLING or CONVERGED
     Compute: Δ = (resolved_issues + convergence_advances) / total_open_issues_in_v{n-1}
     If Δ < Δ_halt (from assay) for TWO consecutive iterations → STAGNATION DETECTED.

  B) NOVELTY SCORE (ν) — Anti-Mode-Collapse
     Compare draft_v{n} against ALL prior drafts.
     Measure:
       — Proportion of symbol derivations that are semantically novel
     If ν < 0.05 (< 5% new structural insight) → MODE COLLAPSE DETECTED.

  C) REGRESSION SCORE (ρ) — Anti-Catastrophic-Forgetting
     Check whether any CONVERGED symbol from register_v{n-1} has regressed to UNSTABLE in register_v{n}.
     Compute: ρ = regressed_symbols / total_converged_in_v{n-1}
     If ρ > ρ_halt (from assay) → CATASTROPHIC FORGETTING DETECTED.

TERMINATION RULES:
  — STAGNATION (Δ < Δ_halt × 2 consecutive)  → HALT. Accept best available version.
  — MODE COLLAPSE (ν < 0.05)                  → HALT. Accept version with highest Δ.
  — CATASTROPHIC FORGETTING (ρ > ρ_halt)      → REVERT to v{n-1}. Accept that version.
  — MAX ITERATIONS reached (from assay)       → HALT. Accept version with best composite score.
  — All three scores nominal + ACCEPT         → SUCCESS. Write lapis_v{n}.md → proceed to demasking.
  — All three scores nominal + REJECT         → Continue to v{n+1}.

COMPOSITE SCORE for tiebreaking:
  S = (Δ × 0.4) + ((1 - ρ) × 0.35) + (ν × 0.25)
  Higher S = better iteration. Used to select "best available" on forced termination.

Write all significance metrics to: significance/scores_v{n}.json

═══════════════════════════════════════════════════════════════
  VIII. HIERARCHICAL CONVERGENCE — ALCHEMICAL NESTING
═══════════════════════════════════════════════════════════════

The Phase Cascade (Section IV) constitutes the INNER LOOP (Albedo-level purification).
The inner loop operates entirely on the MASKED corpus.
Demasking (Section V) occurs ONLY when the inner loop converges.

After demasking, the DEMASKED synthesis becomes input for a MID-LEVEL cycle (Citrinitas):
  — The synthesis is re-submitted as a new corpus (now unmasked, with annotations).
  — A new Phase Cascade runs — this time WITHOUT masking (the structural derivation is complete;
    now we refine the integrated interpretation).
  — Mid-level convergence: when two consecutive outputs show Δ < 0.05 between them.

When mid-level converges, its output feeds the OUTER LOOP (Rubedo-level final integration):
  — Outer convergence: when the mid-level output is stable across two outer iterations (Δ_outer < 0.02).

Nesting depth (governed by assay parameters):
  — Inner loop: max iterations per assay derivation (MASKED)
  — Mid-level: max cycles per assay derivation (DEMASKED)
  — Outer loop: max cycles per assay derivation
  — Significance halting applies at every level independently.

  XI. INVARIANTS — IMMUTABLE LAWS (SULPHUR)
═══════════════════════════════════════════════════════════════

1. MASK INTEGRITY: The symbol map is sealed during the entire inner loop. Reading it before convergence invalidates the entire process. This is the prime invariant.
2. STRUCTURAL DERIVATION ONLY: During masked phases, all meaning must be derived from position, function, relation, frequency, and absence — never from knowledge of what a symbol "is."
3. PROGRESSIVE REVELATION: Every cycle must increase clarity and information density.
4. NON-DESTRUCTIVE: All prior layers, rejected drafts, and the prima materia remain intact and traceable.
5. TRIADIC CONVERGENCE TARGET: symbol ↔ context ↔ inter-context relations.
6. EXPONENTIAL MEMORY: Each level inherits and compounds all prior decrypted states.
7. NO FIXED ITERATION COUNT: Termination driven by significance metrics (with safety maximum from assay).
8. STRICT PHASE ISOLATION: No phase reads files from later phases. Temporal causality is inviolable.
9. CONTRADICTION MINIMUM: Phase 5 must surface the minimum contradictions specified by assay, or explicitly prove with evidence why fewer exist. Fabrication invalidates the cycle.
10. GATEKEEPER INTEGRITY: Phase 7 ACCEPT requires: contradictions ≤ 1, no PROJECTED derivations, all HIGH confidence symbols CONVERGED.
11. SELF-PLAY PERSISTENCE: Every rejected draft + critique is archived and available to all future Phase 2 executions.
12. SIGNIFICANCE HALTING: Stagnation, mode collapse, or catastrophic forgetting trigger automatic termination with best-available output selection.

═══════════════════════════════════════════════════════════════
  XII. EPISTEMISCHE POSITION — TRANSMUTATION VS. PROJEKTION
═══════════════════════════════════════════════════════════════

This system evaluates itself. There is no external verifier — and for hermetic, theological, or esoteric texts there CANNOT be one, because no binary ground-truth exists. The Tabula Smaragdina has no unit test. No one possesses the reference decryption.

This is not a deficiency. It is the epistemological ground condition of the domain.

The relevant distinction is not true vs. false, but TRANSMUTATION vs. PROJECTION:

  TRANSMUTATION: The decryption reveals a structure that was latent IN the corpus itself,
  but hidden. The material is transformed from within. The evidence lies in the text.

  PROJECTION: The agent imposes a structure ONTO the text that corresponds to its own
  training-data statistics, and mistakes the surface for the result. The evidence lies
  not in the text, but in the model.

The masking mechanism enforces this distinction mechanically:
  — With the mask on, the agent CANNOT project — it does not know what the symbols are.
  — With the mask off, the comparison reveals where structure and tradition agree, disagree, or where structure finds something tradition never saw.
  — Phase 4 classifies every derivation as STRUCTURAL, INFERRED, or PROJECTED. PROJECTED is a failure state, not a category of knowledge.

The system cannot guarantee that the result is true. But it can guarantee that it is honest about its own epistemic limits — that it cleanly separates what the text yields, what follows from it, and what remains unknown.

The Stone does not promise gold. It promises that you know what is gold and what is gilded lead.
