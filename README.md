# Hermetics Decoder
An AI prompt that deciphers hermetic texts by resolving symbols in their context taking into respect their context and vice versa.<br>
Example for the results in the repository was "Die geheimen Lehren aller Zeitalter" by Manly P. Hall<br>
<br>
DANGER: Don't use the content of this repository if you don't know what you are doing.<br>
        The results are mostly unsorted! They have been created with several different versions of the prompt.<br><br>
        
To decipher the complete text in a whole and not chapterwise, a 2MB context window of the AI is required.<br>
<br>        
Toned-down version.<br>
If you are bored and don't know hat to do, you could for instance try to change the prompt so it uses 7 iterations in an inner loop and 3 iterations in an outer loop, applying the new insights about archetypes from the inner loop to the original text.<br>
Modify the prompt and compare results. Instruct the AI to track iterations and modifications of archetypes per iteration for deeper insights.<br><br>

Mixed language (english/german) - I'm language-agnostic and can't always remember which language I've written in.<br>
