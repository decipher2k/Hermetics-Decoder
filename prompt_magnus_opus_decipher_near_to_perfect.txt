Once identified (or provisionally selected where indicators align most consistently), designate this as the immutable encrypted prima materia. Save it unchanged in prima_materia/ with full justification trace. NEVER overwrite or mutate the source material.

  IV. SIGNIFICANCE TEST — ANTI-ENDLOSSCHLEIFEN-MECHANISMUS
═══════════════════════════════════════════════════════════════

At each Phase 7 decision, compute a SIGNIFICANCE SCORE to determine whether continued iteration is justified or whether the process should terminate (even on REJECT).

The score has three components:

  A) DELTA SCORE (Δ) — Marginal Improvement
     Compare draft_v{n} against draft_v{n-1} (if exists).
     Measure:
       — Number of substantive changes (not cosmetic rewording)
       — Number of contradictions resolved vs. prior iteration
       — Number of UNKNOWN claims resolved to VERIFIED or INFERRED
     Compute: Δ = (resolved_contradictions + resolved_unknowns + substantive_changes) / total_issues_in_v{n-1}
     If Δ < Δ_halt (from assay) for TWO consecutive iterations → STAGNATION DETECTED.

  B) NOVELTY SCORE (ν) — Anti-Mode-Collapse
     Compare draft_v{n} against ALL prior drafts.
     Measure:
       — Proportion of sentences/claims that are semantically novel (not paraphrases of prior versions)
     If ν < ν_halt (0.05) → MODE COLLAPSE DETECTED.

  C) REGRESSION SCORE (ρ) — Anti-Catastrophic-Forgetting
     Check whether any VERIFIED claim from draft_v{n-1} is now UNKNOWN or contradicted in draft_v{n}.
     Compute: ρ = regressed_claims / total_verified_in_v{n-1}
     If ρ > ρ_halt (from assay) → CATASTROPHIC FORGETTING DETECTED.

TERMINATION RULES:
  — STAGNATION (Δ < Δ_halt × 2 consecutive)  → HALT. Accept best available version.
  — MODE COLLAPSE (ν < 0.05)                  → HALT. Accept version with highest Δ.
  — CATASTROPHIC FORGETTING (ρ > ρ_halt)      → REVERT to v{n-1}. Accept that version.
  — MAX ITERATIONS reached (from assay)       → HALT. Accept version with best composite score.
  — All three scores nominal + ACCEPT         → SUCCESS. Write lapis_v{n}.md.
  — All three scores nominal + REJECT         → Continue to v{n+1}.

COMPOSITE SCORE for tiebreaking:
  S = (Δ × 0.4) + ((1 - ρ) × 0.35) + (ν × 0.25)
  Higher S = better iteration. Used to select "best available" on forced termination.

Write all significance metrics to: significance/scores_v{n}.json

═══════════════════════════════════════════════════════════════
  IX. EPISTEMISCHE POSITION — TRANSMUTATION VS. PROJEKTION
═══════════════════════════════════════════════════════════════

This system evaluates itself. There is no external verifier — and for hermetic, theological, or esoteric texts there CANNOT be one, because no binary ground-truth exists. The Tabula Smaragdina has no unit test. No one possesses the reference decryption.

This is not a deficiency. It is the epistemological ground condition of the domain.

The relevant distinction is not true vs. false, but TRANSMUTATION vs. PROJECTION:

  TRANSMUTATION: The decryption reveals a structure that was latent IN the corpus itself,
  but hidden. The material is transformed from within. The evidence lies in the text.

  PROJECTION: The agent imposes a structure ONTO the text that corresponds to its own
  training-data statistics, and mistakes the surface for the result. The evidence lies
  not in the text, but in the model.

The Phase Cascade makes this boundary visible:
  — Phase 4 (Evidence) forces VERIFIED / INFERRED / UNKNOWN classification per claim:
    "is in the corpus" vs. "I inferred this" vs. "I do not know."
  — Phase 5 (Contradictions) prevents inferences from masquerading as textual findings.
  — Phase 3 (Critique) attacks every projection that presents itself as transmutation.

The system cannot guarantee that the result is true. But it can guarantee that it is honest about its own epistemic limits — that it cleanly separates what the text yields, what follows from it, and what remains unknown.

The Stone does not promise gold. It promises that you know what is gold and what is gilded lead.
